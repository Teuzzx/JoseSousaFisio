## 💡 COMO USAR AS MELHORIAS

### Adicionar Novo Card com Ícone
```html
<div class="service-card">
    <div class="service-icon service-icon-blue">
        <i class="fas fa-dumbbell"></i>
    </div>
    <h3>Meu Serviço</h3>
    <p>Descrição do serviço</p>
</div>
```

### Usar Novas Classes CSS
```html
<!-- Cores de ícone -->
<div class="service-icon-blue">...</div>
<div class="service-icon-green">...</div>
<div class="service-icon-purple">...</div>

<!-- Textos -->
<span class="text-highlight">Destaque</span>
<span class="text-gradient">Gradiente</span>
```

### Ativar Animações
- Cards animam automaticamente ao entrar na viewport
- Números contam animados
- Ícones fazem bounce ao hover
- Tudo 100% automático
