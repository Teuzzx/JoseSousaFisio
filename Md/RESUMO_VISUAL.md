## 🎯 CASOS DE USO

### Adicionar Novo Serviço
```html
<div class="service-card">
    <div class="service-icon service-icon-blue">
        <i class="fas fa-heart"></i>
    </div>
    <h3>Novo Serviço</h3>
    <p>Descrição aqui</p>
</div>
```
→ Recebe automaticamente todas as animações!

### Destacar Texto
```html
<h2>Viva <span class="text-highlight">melhor</span></h2>
```
→ Fica em cor de destaque automaticamente!

### Criar Botão Profissional
```html
<button class="btn btn-primary">
    <i class="fas fa-rocket"></i>
    Clique aqui
</button>
```
→ Já vem com animações e estilos!
