## 🏗️ Arquitetura do Sistema

### FRONTEND
```
index.html
  ├─ Botões "Comprar agora" 
  └─ onclick="redirectToCheckout('product-id')"

checkout.html (NOVA)
  ├─ Formulário de dados
  ├─ Validação de inputs
  ├─ Botão "Pagar com Infinity Pay"
  └─ Salva em localStorage

payment-success.html (NOVA)
  ├─ Confirmação visual
  ├─ Link do Google Drive
  ├─ Download de recibo
  └─ Botão voltar ao site
```

### BACKEND (EmailJS)
```
EmailJS Service
  ├─ Template Cliente
  │  ├─ Assunto: Seu eBook está pronto
  │  ├─ Email do cliente
  │  ├─ Link Google Drive
  │  └─ Dados do pedido
  │
  └─ Template Dono
     ├─ Assunto: Nova venda
     ├─ Email do dono
     ├─ Dados do cliente
     └─ Dados da venda
```

### STORAGE (localStorage)
```
checkout_orders = [
  {
    orderId: "ORD-123...",
    productId: "pilates-kids",
    productName: "Pilates Kids...",
    price: 67.00,
    customerName: "João Silva",
    customerEmail: "joao@email.com",
    customerPhone: "(89) 9 9999-9999",
    timestamp: "2026-01-26...",
    status: "paid"
  }
]
```

## 🔄 Fluxo de Dados

```
1. Cliente clica "Comprar"
   ↓
2. Redireciona para checkout.html?product=pilates-kids
   ↓
3. JavaScript carrega dados do produto
   ↓
4. Cliente preenche formulário
   ↓
5. Submete formulário
   ↓
6. Validação (frontend)
   ↓
7. Salva em localStorage
   ↓
8. Redireciona para Infinity Pay
   ↓
9. Cliente confirma pagamento
   ↓
10. Webh ook do Infinity Pay (opcional)
   ↓
11. Emails são enviados (EmailJS)
    - Email ao cliente com link do eBook
    - Email ao dono com dados da venda
   ↓
12. Redireciona para payment-success.html?orderId=ORD-123
   ↓
13. Cliente vê confirmação + link do Google Drive
```
