### PASSO 3: INFINITY PAY - CONFIGURAÇÃO (10 min)

#### 3A: Sua URL de Checkout

**O que fazer:**
1. Em Infinity Pay, crie seu link customizado de checkout
2. Copie o link
3. Cole em `checkout.js` (linha ~168)

**Onde colar:**

Abra `checkout.js` e procure:

```javascript
// Linha ~168
const infinityPayLink = 'https://app.infinitypay.io/checkout/SEU-LINK-AQUI'; // ← AQUI!
```

**Substitua `SEU-LINK-AQUI` pelo seu link real!**

#### 3B: Webhook URL no Infinity Pay

**O que fazer:**
1. No painel Infinity Pay, procure "Webhooks" ou "Integrações"
2. Cole a URL do Make.com que você copiou no PASSO 2
3. Marque evento "payment.confirmed"

**Onde colar:** Campo "URL do Webhook" em Infinity Pay

```
https://hook.us1.make.com/abc123xyz789def456
```

#### 3C: Redirecionamento em Infinity Pay

**O que fazer:**
1. Em Infinity Pay, procure "Redirecionar após o pagamento?"
2. ATIVE o toggle
3. Cole a URL de redirecionamento

**Onde colar:** Campo "URL de Redirecionamento"

```
https://seu-dominio.com/payment-success.html?orderId={order_id}
```

⚠️ **SUBSTITUA `seu-dominio.com` pelo domínio real!**

Exemplos:
- Se domínio é `drdossouafisio.com.br`:
  ```
  https://drdossouafisio.com.br/payment-success.html?orderId={order_id}
  ```

- Se domínio é `fisioterapiajose.com.br`:
  ```
  https://fisioterapiajose.com.br/payment-success.html?orderId={order_id}
  ```

**Checklist:**
- [ ] Colei meu link Infinity Pay em checkout.js
- [ ] Colei webhook URL do Make.com em Infinity Pay
- [ ] Ativei "Redirecionar após pagamento?" em Infinity Pay
- [ ] Colei URL de redirecionamento em Infinity Pay

## ❓ DÚVIDAS?

### "Qual é meu domínio?"
Se o site é:
- `meusite.com` → domínio é `meusite.com`
- `www.meusite.com.br` → domínio é `meusite.com.br`
- `fizioterapia.local` → domínio é `fizioterapia.local`

### "Onde acho meu link Infinity Pay?"
1. Acesse painel Infinity Pay
2. Procure "Criar Checkout" ou "Link de Pagamento"
3. Crie um novo
4. Copie o link customizado

### "Não recebi o email?"
1. Verifique spam/lixo
2. Verifique que Make.com está "ON"
3. Verifique no Make.com → History se teve erro
4. Teste manualmente em Make.com

### "Cliente não foi redirecionado?"
1. Verifique URL em Infinity Pay (sem typos)
2. Verifique que colocou `{order_id}` no final
3. Teste um pagamento real (simulado às vezes falha)
