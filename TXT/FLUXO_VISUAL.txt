## 🔄 DADOS QUE CIRCULAM

### 1. Checkout.html → localStorage
```json
{
  "orderId": "ORD-1234567890",
  "productId": "pilates-kids",
  "productName": "Pilates Kids – Guia Prático",
  "price": 67.00,
  "customerName": "João Silva",
  "customerEmail": "joao@email.com",
  "customerPhone": "(89) 99999-9999",
  "timestamp": "2026-01-26T10:30:00Z",
  "status": "pending_payment"
}
```

### 2. Cliente → Infinity Pay
```
URL do checkout do Infinity Pay:
https://app.infinitypay.io/checkout/seu-link-customizado
```

### 3. Infinity Pay → MAKE.com (Webhook)
```json
{
  "event": "payment.confirmed",
  "orderId": "ORD-1234567890",
  "amount": 67.00,
  "customerEmail": "joao@email.com",
  "customerName": "João Silva",
  "customerPhone": "(89) 99999-9999",
  "productId": "pilates-kids",
  "productName": "Pilates Kids – Guia Prático"
}
```

### 4. MAKE.com → Gmail
```
Email 1 (Cliente):
  TO: joao@email.com
  SUBJECT: ✅ Pilates Kids - Seu eBook está pronto!
  BODY: Link + ID de pedido

Email 2 (Dono):
  TO: seu-email@gmail.com
  SUBJECT: 💰 NOVA VENDA - Pilates Kids
  BODY: Dados do cliente + valor
```

### 5. Infinity Pay → Cliente (Redirect)
```
Redireciona pra:
https://seu-dominio.com/payment-success.html?orderId=ORD-1234567890
```

### 6. Payment-success.html → localStorage
```
Lê: checkout_orders
Exibe: Dados do pedido + link eBook
```
