## 🔗 Configuração do Infinity Pay (5 min)

### Passo 1: Copiar Link
```
Vá em: infinitypay.io
Menu: Configurações → Links de Pagamento
Crie: Um novo link
Copie: O link completo
```

### Passo 2: Editar script.js
```javascript
Procure por: proceedToPayment()
Encontre: const infinityPayLink = ...
Substitua: por seu link do Infinity Pay

ANTES:
const infinityPayLink = `https://infinitypay.io/checkout?...`;

DEPOIS:
const infinityPayLink = 'https://seu-link-aqui.com';
```

### Passo 3: Salvar e Testar
```
1. Salve: Ctrl+S
2. Abra: seu site no navegador
3. Clique: "Comprar agora" em um eBook
4. Confirme: Modal abre e funciona
5. Pronto: Sistema operacional!
```
