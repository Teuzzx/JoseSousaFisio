### ⏰ Minutos 5-20: MAKE.com Setup

```
AÇÃO 4: Acesse make.com
   → https://www.make.com
   → Clique "Sign up free"
   → Email, senha, país (Brasil)
   → Confirme email

AÇÃO 5: Crie Webhook
   → Em Make.com: Scenarios → Create new
   → Procure "Webhooks"
   → Clique "Custom Webhook"
   → Copy webhook URL (tipo: https://hook.us1.make.com/abc123)
   → **SALVE EM BLOCO DE NOTAS!**

AÇÃO 6: Conecte Gmail
   → Em Make.com: "+ Add module"
   → Procure "Gmail"
   → Clique "Send an Email"
   → Create new connection
   → Login com seu Gmail
   → Autorize

AÇÃO 7: Crie 2 Emails
   → Email 1 para cliente (com link eBook)
   → Email 2 para você (notificação venda)
   → Siga modelo em MAKE_COM_SETUP.md
   → Ative o cenário (botão "ON")
```

✅ **Resultado:** Webhook URL pronto, emails configurados

---

### ⏰ Minutos 20-30: Infinity Pay Config

```
AÇÃO 8: Configure checkout.js
   → Abra checkout.js
   → Linha 168: const infinityPayLink
   → Cole seu link Infinity Pay
   → Salve com Ctrl+S

AÇÃO 9: Configure Infinity Pay
   → Abra painel Infinity Pay
   → Vá em Webhooks
   → Campo "URL do Webhook": Cole a URL do Make.com
   → Eventos: Marque "payment.confirmed"
   → Salve

AÇÃO 10: Ative Redirecionamento
   → Em Infinity Pay
   → Procure "Redirecionar após o pagamento?"
   → ATIVE o toggle
   → URL: https://seu-dominio.com/payment-success.html?orderId={order_id}
   → Salve
```

✅ **Resultado:** Infinity Pay totalmente configurado
