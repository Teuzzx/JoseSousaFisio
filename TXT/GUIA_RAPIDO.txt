## ⚡ 3 COISAS QUE VOCÊ PRECISA FAZER

### 1️⃣ GOOGLE DRIVE LINKS (5 min)

**Arquivo:** checkout.js (linhas 10-15)

Substitua os 3 links:

```javascript
// Linha 10
'pilates-kids': {
    googleDriveLink: 'https://drive.google.com/file/d/1234567890/view?usp=sharing', // ← COLOQUE SEU LINK AQUI
}

// Linha 16
'exercicios-alunos': {
    googleDriveLink: 'https://drive.google.com/file/d/0987654321/view?usp=sharing', // ← COLOQUE SEU LINK AQUI
}

// Linha 22
'documentos-studio': {
    googleDriveLink: 'https://drive.google.com/file/d/1111111111/view?usp=sharing', // ← COLOQUE SEU LINK AQUI
}
```

**Como copiar link Google Drive:**
```
1. Abra seu arquivo no Google Drive
2. Clique botão "Compartilhar"
3. Escolha "Qualquer um com o link" > "Visualizador"
4. Copie o link (tipo: https://drive.google.com/file/d/abc123/view?usp=sharing)
5. Cole em checkout.js
```

### 2️⃣ MAKE.COM - EMAIL AUTOMÁTICO (15 min)

**Arquivo:** MAKE_COM_SETUP.md (LEIA TUDO!)

**Resumido:**

---

### 3️⃣ INFINITY PAY - CONFIGURAÇÃO (5 min)

**Arquivo:** INFINITY_PAY_CONFIG.txt

**2 Coisas:**

**A) Coloque sua URL de Link de Checkout:**

No checkout.js (linha 168):

```javascript
const infinityPayLink = 'https://app.infinitypay.io/checkout/SEU-LINK-AQUI'; // ← SUBSTITUA
```

Como conseguir? Vá em Infinity Pay → Crie seu link customizado → Copie → Cole aqui

**B) Configure Infinity Pay:**

1. Em Infinity Pay, vá em Webhooks
2. Cole URL do Make.com em "URL do Webhook"
3. Ative "Redirecionar após pagamento?"
4. Cole: `https://seu-dominio.com/payment-success.html?orderId={order_id}`

## 🆘 TROUBLESHOOTING

### Cliente não redireciona pra success page?
```
✓ Verifique URL em Infinity Pay (sem typos)
✓ Formato correto: https://seu-dominio.com/payment-success.html?orderId={order_id}
✓ Infinity Pay tem "Redirecionar após pagamento?" ativado?
```

### Email não chegou?
```
✓ Make.com scenario está "ON"?
✓ Gmail está autorizado?
✓ Verifique spam/lixo
✓ No Make.com, clique "History" pra ver erro
```

### Webhook não foi acionado?
```
✓ URL do Make.com está colada certa em Infinity Pay?
✓ Eventos "payment.confirmed" está marcado?
✓ Faça um teste real (não simulado)
✓ Verifique "History" no Make.com
```
